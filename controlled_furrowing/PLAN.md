# Controlled furrowing: five-gate execution contract

Objective: complete the five gates for the candidate that one mechanically consistent model, calibrated only on small activated tissue regions, predicts larger-region deformation without condition-specific refitting. This is a separate study from the quail kinematic-mask experiment. No originality or predictive success is assumed.

1. **Exact originality audit.** Compare the specific cross-geometry calibration/prediction claim against primary papers, supplements and models, including Countryman et al. 2025 (10.1038/s41467-025-62483-6). Record equations, fitting inputs, predicted outputs and access limits. Reject an already established claim as novel; an honest reproduction remains labeled reproduction.
2. **Actual data feasibility.** Download and parse source measurements, with hashes and units. Establish small-region calibration and larger-region evaluation records, specimen identity or its absence, activation input, geometry, timing and observation operator. Public source tables and illustrative movies are not silently promoted to complete raw acquisitions.
3. **Minimal adequate model and identifiability.** Derive a mechanically defensible model and declare validity assumptions. Cell height is comparable to activation diameter, so a thin-sheet approximation needs justification. Infer observable parameter combinations from calibration records only. Carry unresolved parameter sets into predictions; do not choose them using larger-region outcomes.
4. **Frozen prediction.** Lock equations, calibration, parameter uncertainty, comparison norms and decision rules before computational scoring. Save actual larger-region predictions before loading held-out responses into the scorer. Published outcomes are known; this is retrospective computational withholding, not blind new experimental validation. No new condition-specific fitted parameters, hidden future geometry or post-score model selection.
5. **Contribution assessment.** Compare against simpler declared models, measurement limits, numerical sensitivity and nearest published work. A novel contribution requires a substantive demonstrated difference; a failed fit is not automatically an original negative theorem. Report correctness, predictive success and novelty separately.

Every gate requires retained files and an independent check appropriate to the claim. A well-executed gate may reject its scientific hypothesis. Missing evidence is INCOMPLETE or BLOCKED, never PASS by redefinition. Gates 3–5 are not marked executed merely because gates 1–2 encounter a problem. Any conditional no-go branch names what prevents further justified work.

No author contact, new wet-lab experiment, public GitHub publication or confirmed novelty is implied by this contract. Existing source data and prior outcomes already seen remain explicit. The active goal remains the complete five-gate study, not only this contract or the audit.
