From a verified nodal error to the measured static endpoints

A bound on nodal coordinates can be transferred rigorously to the current-radius observer. No actual mechanical error radius is supplied by this result. It is one conditional link needed between a future algebraic-root certificate and observable uncertainty. Quadrature, continuum, temporal and experimental errors remain separate.

The implementation and thirteen exact synthetic checks use rational arithmetic. An independent review is still required before this component is used to support a physical error claim. An initial generic API gap allowed composition of different default surface ROIs; the corrected implementation requires a shared ROI. Independent review also required positive ROI width before claiming bounds for normalized means. The preceding sources, tests and findings are retained under runs/nodal_error_transfer/initial_revision/ and pre_mean_mass_guard/, before any application to an actual mechanical error bound.
