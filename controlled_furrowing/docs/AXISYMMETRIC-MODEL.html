A coupled finite-height axisymmetric solid

This component implements a three-dimensional elastic body restricted to axisymmetric motion. It is a conditional mathematical model of a circular activation patch coupled to surrounding tissue. It is not a plate, a specimen reconstruction, a calibrated biological constitutive law, or a prediction of the observed transient bending label. No experimental outcome is read by the mechanics module.

The construction, constitutive choices, automatic differentiation and continuation are standard methods. This implementation makes no originality claim.

Discretization and a useful exact orientation check

The meridian is triangulated with continuous piecewise affine displacement. The radial grid contains , and the height grid contains both activation-depth boundaries, so an activated triangle does not straddle the prescribed discontinuity. The meridional gradient is constant on a triangle. The hoop stretch varies as a ratio of affine functions. Triangle quadrature can use degrees 1, 2 or 4; independent Gauss surface quadrature uses 1, 2, 3, 5 or 8 points. The default uses degree 2 in the volume and 3 surface points.

The code tests these bounds rather than asserting orientation from quadrature samples alone. Floating point calculations are not interval certificates. Positive local orientation does not prove global injectivity or absence of self-contact.

The current volume is . Its affine integrand makes the discrete volume exact in real arithmetic for all supported triangle quadratures. The nonlinear elastic energy and surface energy have quadrature error.

The optimizer uses bounded L-BFGS followed by automatic-differentiation Hessian/Newton polishing with backtracking. A temporary extension penalizes inverted trial states; its penalty must be exactly zero on every reported physical solution. The accepted convergence gate requires the normalized free nodal force infinity norm below , positive elementwise orientation and stationary continuation stages. Raw L-BFGS success flags remain in every record: a short L-BFGS stage can hit its iteration limit and then pass the independent force gate after Newton polishing.

This is a displacement-only P1 penalty method. Near-incompressible locking and insufficient local resolution are real limitations. Small residuals show that the chosen discrete equations were solved; they do not bound continuum discretization error.

Outputs, observation limits and units

The result retains every reference/current node and triangle, free displacement vector, material activation mask, full apical/basal boundary profiles, signed central displacements, volume, elementwise bounds, sampled stretches, energies and continuation diagnostics. If each boundary is radially monotone, the code constructs a common Eulerian radial grid containing every top/bottom breakpoint. The two piecewise-linear graphs can then be passed without arbitrary crest thresholds to the separate slice observer.

The reported material-column vertical height , the distance between those material endpoints, and the Eulerian graph thickness are different observables. The code labels them separately. maximum_activated_column_shortening is a static equilibrium proxy over material columns. The experimental statistic is a maximum over time; equating these requires an independent observation/kinetic argument and is not established here.

API and replay

from axisymmetric_mechanics import Parameters, build_model
model = build_model(Parameters(nr=8, nz=4))
first = model.relax(0.2)  # one fixed-strength solve, no zero reset
second = model.relax(0.5, first['free_displacement'])
# For ramp-work bookkeeping with a declared previous gain:
ramped = model.solve(0.5, initial=first['free_displacement'],
                     continuation_start_strength=0.2,
                     continuation_steps=1, maxiter=100)

relax starts its work ledger at the same fixed strength; it does not pretend to include the previous activation increment. A normal solve starts at zero gain by default and performs continuation. All returned vectors are directly reusable only for the same mesh/material reference. A caller should set Torch's thread count appropriately; the CLI self-test uses one thread.

python -B controlled_furrowing/scripts/axisymmetric_mechanics.py --self-test

Verification receipts and limitations

The premeasurement thresholds are retained in evidence/axisymmetric_protocol.json. Checks include zero-dose identity, an exact isochoric affine deformation, its analytic bulk/surface energy, directional derivatives checked by finite differences, positive-J activated equilibria, an external-potential ledger, uniform material/activation scaling and independent mesh/quadrature/domain/basal-modulus/reference-curvature sensitivity runs.

The first run failed its force tolerance because L-BFGS stopped on relative objective reduction. It remains intact in runs/axisymmetric/initial_failure/. Newton polishing was added; no force threshold was relaxed. The intermediate successful version and receipt remain in runs/axisymmetric/newton_verified_v1/. evidence/axisymmetric_verification.json records the final replay and source hash. evidence/axisymmetric_warm_start.json records the fast warm-start test; its exact older source hash is retained, and subsequent changes exposed surface quadrature without changing defaults.

At gain 0.2 in the synthetic default geometry, shortening changes from approximately 0.010995H on 8×4 cells to 0.013587H on 12×6 and 0.016541H on 16×8. All are stationary to about in normalized nodal force. This is substantial unresolved mesh sensitivity, not numerical convergence evidence. It blocks a rigorous continuum prediction or a narrow error bar from this implementation alone. Quadrature, outer clamp, basal modulus and curvature sensitivity must also accompany any exploratory calibration.
