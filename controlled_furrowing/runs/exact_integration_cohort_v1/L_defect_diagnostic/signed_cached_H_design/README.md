# Signed cached Hessian on the original L predictor cube

This is a feasibility design for the same 611-free-coordinate finite-element model, binary cache convention, exact-integral target, parameter cell, and selected local branch used in the prior L reduction. It uses static source and accepted receipts. The figures below are carried forward from those receipts. The signed cached bound itself remains uncomputed.

## Decision rule

Write \(F_Q,H_Q\) for the cached force and Hessian and \(F_I,H_I\) for the exact-integral force and Hessian. The preconditioner \(R\) is the same frozen binary witness. The earlier whole-cube upper bounds are \(Z_Q=0.3831477190712284\) and \(b\approx5.18008261328981\times10^{-5}\) for \(\|I-RH_Q\|_\infty\) and \(\|R(H_I-H_Q)\|_\infty\), respectively. The resulting earlier bound for the exact-integral map is \(z_I\approx0.38319951989736134\). The old cube radius is \(r\approx6.011722184963558\times10^{-11}\). Use the exact or outward endpoints in the certificates when making a strict comparison. The cached center-only bound \(Z_0\approx1.4107\times10^{-6}\) controls only \(I-RH_Q(u_0,\theta_0)\).

Let \(\eta_I\) be an accepted upper bound on \(\sup_{\theta\in C}\|RF_I(p_\theta,\theta)\|_\infty\). A direct signed exact-integral bound already contains the cached force and must enter the test once. If it passes with the old \(z_I\), use the existing derivative bound. Otherwise define the strict threshold \(\tau=1-b-\eta_I/r\). At fixed \(b,r,\eta_I\), a revised cached bound must satisfy \(Z_Q^{\rm new}<\tau\). If \(\tau\le0\), redoing this bound alone cannot establish self-map. If \(0<\tau\le Z_Q\), check whether a signed cached replay can reach the threshold. The design gives no guarantee of improvement. A valid new cached result can be combined as \(z=\min(Z_Q,Z_Q^{\rm new})+b\) with outward arithmetic. If already validated signed entries of \(R(H_I-H_Q)\) cover the same cube, an additional enclosure can combine them with the signed cached product before row norms and retain the better proven bound. With \(z<1\) and \(\eta_I+zr<r\), Banach gives a unique finite-element root in the cube for each \(\theta\). Since \(RH_I\) is square and within distance \(z<1\) of identity, \(R\) is invertible and a fixed point has zero force. Failure of a sufficient inequality leaves the root unresolved. ## Enclosure on the frozen family

For \(p_\theta=u_0+S(\theta-\theta_0)\) and \(\|e\|_\infty\le r\), cache site \(t\) has
\[
q_t=q_t^0+P_t(\theta-\theta_0)+B_t e,\qquad P_t=B_t S_{\mathrm{local},t}.
\]
Use the exact archived \(u_0,\theta_0,S,R\), five-coordinate order, closed cell \(C\), exact radius and dose, reference coordinates, cache rules and active mask. Expand the reference and fixed-coordinate values in \(q_t^0\), and use free columns only in \(B_t\). The same local \(B_t\) and normalized \(w_t\) must enter the center and tube formulas. The original enclosure uses the hull of the parameter offsets with zero. Reusing that box suffices. For a uniform derivative only, a smaller offset hull obtained directly from \(C-\theta_0\) is sound if its endpoint arithmetic encloses the entire fixed family. Use outward local bounds \(|(B_t e)_a|\le r\sum_j |(B_t)_{aj}|\). Bulk hoop and surface reference factors include quotients of frozen binaries, so use their exact rational definitions or enclosing arithmetic. Check the actual cached site count \(144\times64+24\times12=9504\), with each term once.

For bulk, retain the same \(\mu,\kappa\) and active Hessian diagonal drive \(I\,g\,\mathrm{mask}_t\) with exact dose \(I\), varying gain \(g\), and the center value from the same law at \(\theta_0\). Keep \(\det F_{\mathrm{plane}}>0\), hoop stretch \(h>0\), and \(J>10^{-6}\) at all bulk quadrature sites. For each surface, retain its cache scale, orientation, reference and weight, and the appropriate \(K,T\) entries of the same parameter cell. With \(J_s=\mathrm{scale}\,R_{\mathrm{rad}}|t_{\mathrm{tan}}|\), its local Hessian is \(K\nabla J_s\nabla J_s^T+[K(J_s-1)+T]\nabla^2J_s\). Check positive deformed radius and squared tangent length, positive scale and reference data, positive normalization, and confirm the archived normalized weight signs or include them literally in signed arithmetic. Keep all bulk and surface terms, including the surface contribution to the difference. Verify the axis regularization and inactive penalty branch used by the frozen cache. [Old coupled variation](../../../../scripts/parametric_root_cells.py#L159) · [Cached local Hessians and site maps](../../../../scripts/algebraic_root_feasibility.py#L62)

Let \(L_t\) denote the local Hessian in site coordinates. For every admissible state, assemble
\[
\Delta H_Q=H_Q-H_{Q,0}=\sum_t w_t B_t^T\big[L_t(q_t,\theta)-L_t(q_t^0,\theta_0)\big]B_t,
\qquad H_{Q,0}=H_Q(u_0,\theta_0).
\]
With outward enclosures of each difference, retain signs in projection and global scatter. For each local symmetric off-diagonal \(L_{ab}\) use its single coefficient \(B_{ai}B_{bj}+B_{bi}B_{aj}\) in projected entry \((i,j)\). The diagonal uses \(B_{ai}B_{aj}\). Straight interval subtraction of the two local Hessians is valid. A verified analytic split can tighten it, for example separating the exact affine drive increment before projection. Independently reconstruct \(H_{Q,0}\) and preserve the signed enclosure \([D_0]=I-R[H_{Q,0}]\). Then
\[
[D_Q]=[D_0]-R[\Delta H_Q],\qquad
Z_Q^{\rm new}=\max_i\sum_j\max(|\inf[D_Q]_{ij}|,|\sup[D_Q]_{ij}|).
\]
The original variation takes absolute values before the global scatter and preconditioner multiplication. The signed calculation can keep cancellations through those steps, while the chosen local interval extensions may still be wide. An optional direct enclosure \(I-R[H_Q(\mathrm{tube})]\) represents the same quantity and can be intersected entrywise.

## Efficient arithmetic and independent review

Stream 9,504 local packets into a sparse canonical upper triangle. Reflect upper entries when producing sparse columns for signed left multiplication by \(R\). Derive the support from the actual maps, including all surface entries. For entrywise midpoint/radius form \([\Delta H_Q]=M\pm W\), the safe product rule is \(RM\pm|R|W\). Compute the midpoint products and positive radius sums exactly or with outward rounding that also covers midpoint-product error. Block by column or row and retain signed row endpoints and their maximum with exact or outward reductions. Ordinary row summation relaxes correlations. In particular one off-diagonal Hessian scalar occurs in two product columns. If a later optimization exploits symmetry in a fixed row sign expression \(\sum_j \sigma_j(R\Delta H_Q)_{ij}\), its combined coefficient for entry \(a<b\) is \(R_{ia}\sigma_b+R_{ib}\sigma_a\). A valid improvement needs an upper bound over all sign vectors. A maximizing sign vector found numerically gives a lower bound for that maximization.

A future independent receipt should pin the computation source, local kernel sources, original L protocol/box and root/geometry receipts, binary cache payload and ordered arrays, original \(S/R/C/r/\theta_0/I\), dose and face/material maps, precision and rounding instructions, and the accepted same-domain exact-integral Hessian defect. It should verify every coverage key, both local analytic domains, center-versus-tube parameter identities, index/scatter symmetry and signs, and signed endpoint propagation through \(D_0\), \(R\Delta H_Q\), the row bounds and the strict self-map test. Use a separately implemented endpoint/product reduction or equivalent independent replay, state any shared local analytic kernels, preserve failed attempts, and bind the actual terminal output and accepted direct force interval. A synthetic check with nonsymmetric \(R\), negative projection coefficients and a shared off-diagonal interval can guard against taking absolute values too early or assuming independent entries in a sharper product.

The earlier cached energy result already proves \(\operatorname{sym}(R)\succ0\) and \(H_Q\succ0\) on this same full cube. A sharper bound leaves that premise intact. For symmetric exact-integral \(H_I\), an accepted combined bound \(Z_Q+b<1\) gives positivity there by the nonsingular symmetric homotopy \(H_s=H_Q+s(H_I-H_Q)\), since \(\|I-RH_s\|_\infty\le Z_Q+s b<1\). The same argument accepts a proved smaller \(Z_Q\). Positive curvature is a statement about the Hessian over this finite model domain. An energy minimum at a stationary point also requires establishing the root. [Old energy proof](../../../../docs/COHORT-ENERGY-STABILITY.md)

## When to prefer a translated cube

For a fixed shift \(s\), a candidate \(p_\theta-s+[-r_1,r_1]^{611}\) stays inside the old geometry if \(\|s\|_\infty+r_1\le r\). Let \(E_\theta=RF_I(p_\theta,\theta)\). With the same \(z\) on the connecting segment and translated cube, the shift estimate is
\[
\eta_1\le \sup_\theta\|E_\theta-s\|_\infty+z\|s\|_\infty .
\]
Using the largest allowed \(r_1\) makes the sufficient test \(\sup_\theta\|E_\theta-s\|_\infty+\|s\|_\infty<(1-z)r\). For the same force enclosure and derivative bound, this implies the old sufficient test by triangle inequality. Thus shift and radius reallocation alone cannot resolve a failed old test with those bounds.

A translated route becomes competitive if already available signed Hessian entries yield a much sharper derivative action along \(s\), if a smaller coupled tube materially reduces the derivative bound, or if a sharper validated translated residual is cheap. Separately bound the derivative along the bridge \(p_\theta-\lambda s\) for \(0\le\lambda\le1\) and throughout the translated cube, unless the chosen derivative domain covers both. Reuse the same-domain Hessian defect on either subset as appropriate. The upper limit on \(r_1\) decreases with \(\|s\|_\infty\), so compare strict margins before launch. If the unchanged-cube target is positive and moderate, a sparse signed cached replay directly tests the needed improvement and covers the original cube. If the target is nonpositive, prioritize a sharper force bound, a sharper defect bound, or a translated test supported by new quantitative bounds. Neither design establishes anything about a continuum PDE, physiological parameters, or any equilibrium outside its admitted cube.
