# Observer transfer for all 36 cached roots

The admitted set is two fixed parameter vectors, each with 17 nonzero small-region fields and one large final field. The executable requires one unique independently proved cached-quadrature root per archived field, checks recorded strict contraction and error inequalities, and retains the two original unresolved certificates separately from their successful recentered proofs. The input roots are four pilots, two M cases, 28 roots from the eight subsequent waves, and two recentered roots. The exact-spatial certificates have a separate scope and are outside this calculation.

For an archived displacement \(u_0\), let \(\xi_0\) bound the difference between the exact real coordinate sum \(X+u_0\) and the coordinate array serialized in the original field. Let \(\sigma=\|u_1-u_0\|_\infty\) be the actual exact displacement of the binary verification center, with \(\sigma=0\) when verification used the archived center. The independently proved posterior root error measured from \(u_1\) is \(e=\eta/(1-z)\). The original observer budget requires \(\sigma+e<e_{\rm goal}\) and the archived coordinates differ from the root coordinates by at most
\[
\varepsilon=33.5\,(\xi_0+\sigma+e)\quad\text{µm}.
\]
In particular, this calculation uses \(\xi_0\) from the original drawings and predictions even for the two recentered states. It leaves the observer curves, references, allowance and recorded target measurements attached to the archived inputs.

The reviewed P2 graph bound uses \(\sum_i|N_i|\le5/4\) and \(\sum_i|N_i'|\le8\). The same reduced free map fixes the radial axes and rims. The code reconstructs the archived P2 controls, both fixed radial trace endpoints, the reference height, the equation for the archived addition gap, and the coverage of each fixed current-radius region. The strict derivative check \(m_{\rm archived}>8\varepsilon\) ensures monotonic root traces on each trace edge. The slopes of the archived graphs then convert nodal error into Eulerian vertical error bounds \(E_a\) and \(E_b\). This supplies an error bound \(E_a+E_b\) for the spatial maximum and the disk average of shortening and \(E_a,E_b\) for the separate apical and basal spatial maxima. Fixed reference functions, conforming traces and normalized nonnegative averaging weights are essential. The calibration result compares the maximum absolute residual over each inflated signed interval to the original closed allowance. There are 68 comparisons per endpoint.

For each large state \(Q=Z_a(0)-Z_a(R_{\rm shoulder})\), the center is a fixed-axis radial node. Its vertical error bound is \(\varepsilon\). The shoulder is at the same fixed current radius and uses \(E_a\), so the total \(Q\) error bound is \(\varepsilon+E_a\). The positive-direction interval minus the negative-direction interval yields the signed large gap. Strict separation is reported only if the entire resulting interval is positive. No held-out responses are used.

The cold package reads pinned premise receipts and runs only synthetic fixtures. Actual application requires a separate root source review, plus exact external hashes for the independent recenter receipt and observed process exit. The result applies to the declared frozen disk/spatial-maximum observer and its explicit discrepancy. The existing alternate-observer checks, exact-spatial coverage work, mechanical branch assessment and source observation compatibility remain separate.
