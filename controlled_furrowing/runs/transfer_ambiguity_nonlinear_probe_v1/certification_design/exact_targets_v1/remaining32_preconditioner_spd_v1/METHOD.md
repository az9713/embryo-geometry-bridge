# Symmetric parts of 32 fixed preconditioners

For each remaining fixed-input target, use the exact binary entries of the frozen matrix \(R\) to define \(P=(R+R^{\mathsf T})/2\). The context binds the source field, proof center, optional original archived center shift, exactly prescribed gain times dose, cache, normalization and free-coordinate order. The matrix stage applies to those already frozen objects.

An ordinary floating Cholesky factor of the rounded proposal for \(P\) suggests a matrix \(K\). The certificate starts from exact binary entries of \(R,K\), forms \(P\) in outward interval arithmetic, and bounds

\[
 q\ge \|I-K P K^{\mathsf T}\|_\infty.
\]

The producer evaluates \((KP)K^{\mathsf T}\). A second association evaluates \(K(PK^{\mathsf T})\) after reading the exact saved proposal. Both sufficient checks require \(0\le q<1\). Since \(KPK^{\mathsf T}\) is symmetric, a defect bound smaller than one places its eigenvalues strictly above zero. Positive definiteness of the congruence also forces the square \(K\) to be nonsingular. Congruence then gives \(P\succ0\). The argument allows nonsymmetric \(R\). An unsuccessful proposal or sufficient check leaves the case unresolved.

Each case links the original authenticated cache packet, its embedded payload and exact \(R\) entry bytes. The new \(K\) archive is hashed both as an NPY file and as exact matrix bytes. The exact dyadic row sums determine \(\|R\|_\infty\), which must match the same joined derivative and geometry input. The original cache supplies the authoritative \(R\) file, so there is one \(K\) archive per successful proposal. The serial launcher retains the started file, each result, the aggregate manifest, and a native terminal. The observed operating-system exit must be recorded separately.

## Independent actual review

An independent reviewer should require the externally observed successful serial process, native manifest and terminal, all ordered case hashes, and every linked same-target context before opening matrix archives. For each case the reviewer should extract \(R\) from the original cache, compare its exact bytes, load the frozen \(K\), and recompute the congruence defect and the row norm from exact binary values. The reviewer can use the already reviewed alternate association with a separate endpoint computation. A producer's second-association result remains producer evidence and requires this independent calculation. A review may certify the successful cases and retain explicit unresolved cases.

Positive \(\operatorname{sym}R\) is an input to a later minimum proof. Stationarity and a whole-cube exact-spatial Hessian bound are separate obligations. The matrix stage computes no forces, spatial integrals, AD or solutions and changes no observer data.
