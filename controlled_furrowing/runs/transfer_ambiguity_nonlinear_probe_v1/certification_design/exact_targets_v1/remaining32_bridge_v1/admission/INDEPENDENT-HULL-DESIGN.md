# Independent enclosure and hull authority for the first spatial wave

This is a mathematical design for the four new remaining32 targets. It authorizes no component jobs and does not revise the four earlier independently reduced singleton certificates.

## Validity premise

For each routed component, the independent calculation must prove two statements with its own mathematics and directed arithmetic.

- At the exact point center \(u_c\), its signed vector interval \(A_F\) contains the corresponding component of \(F_I(u_c)-F_Q(u_c)\).
- For every \(u\) in the same closed fixed-parameter cube, its signed symmetric upper matrix interval \(A_H\) contains the corresponding component of \(H_I(u)-H_Q(u)\).

Here \(I\) is the exact-spatial operator and \(Q\) is the same binary-cache quadrature operator certified in the retained point and derivative inputs. The independent calculation must regenerate the point force, whole-box derivative, the signed same-deformation auxiliary-to-cache corrections, and the relevant bounded analytic series and tails. A shared reviewed local primitive is an explicit premise. The evidence must cover both reference quadrature and cache sites, correct outward endpoints, admissible analytic domains, point versus whole-box roles, both masses where used, exact active drive, normalization, local projection, and correct symmetric entry order. Earlier source or kernel review alone supplies none of the case-specific numbers. Point intervals and uniform Hessian intervals are assessed separately.

## Enclosure consumed by the reduction

For each matching signed entry define
\[
\operatorname{hull}(A,B)=
\left[\min(\underline A,\underline B),\ \max(\overline A,\overline B)\right],
\]
where \(A\) is the independently established interval and \(B\) is the producer's corresponding serialized signed interval. Each hull contains \(A\) by construction. This remains true if \(B\) misses \(A\) by a rounding unit, if the pair overlaps without containment, or if the pair is disjoint. The whole-box Hessian statement holds for every cube point because the same independently valid uniform interval is contained in the hull.

The geometry branch, parameters, box coordinates, active drive, normalization, cache realization, projected coordinates, and slots of both bundles must match. Incorrect or ambiguous identity, an incomplete packet, or failed independent enclosure construction prevents admission. A malformed producer record may independently prevent use of this particular bundled protocol. The mathematical enclosure does not use an accuracy claim for the producer. Preserve each exact producer and independent endpoint, inclusion test, and disjointness diagnostic. A complete valid hull receipt may report failed containment, but it must never report that the producer passed strict containment when it did not. A disjoint pair contradicts the proposition that both validly enclose the same quantity and needs explicit investigation before any joint claim of two-way agreement.

## Signed reduction and scope

The downstream proof must consume the actual serialized hull endpoints and never silently select the narrower producer endpoints. Rehash the full 168-route manifest, all native independent and raw payloads, the separately observed process exits, and the exact point anchor and derivative bounds. Use the original projected coordinate order when adding the local signed entries. Mirror each upper Hessian off-diagonal exactly once. Use signed preconditioned point defects before norms and add the already preconditioned cached force once. For the derivative use the exact product enclosure and combine it with the same-cube cached \(Z_Q\). Taking larger intervals may decrease the available margin. If the sufficient strict self-map or local minimum inequalities fail, retain that outcome without inferring nonexistence. The method proves exact-spatial finite-element bounds only after these separate root checks have actually passed.

Independent valid entries alone would also suffice and are narrower. The hull preserves both numerical inputs as outward evidence and never uses overlap as a premise. No risk of false promotion is removed merely by changing a status name. This design requires its own source and mathematical review before any actual packet replay or reduction.
