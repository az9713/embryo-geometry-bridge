# Originality follow-up for the frozen transfer-ambiguity probe

**The general concept is already established.** Same-law parameter sets can agree on the available observations yet give different responses to a new intervention. Liu, Maini and Baker explicitly describe that strategy and work a two-parameter-set example in one logistic law. Peloquin and Elliott make the transfer concern explicit for biomechanics when geometry and load change. The present research question is whether a particular, reproducibly defined epithelial model admits such a pair under all 68 declared small-region constraints, while holding the larger input and observation fixed. That remains a prospective application result. [Liu, Maini and Baker, §§1.2 and 3.1](https://people.maths.ox.ac.uk/maini/PKM%20publications/563.pdf) · [Peloquin and Elliott, §4.1](https://royalsocietypublishing.org/rsif/article-pdf/doi/10.1098/rsif.2024.0415/930826/rsif.2024.0415.pdf)

## What a separating witness would establish

Declare one law, scale convention, admissible geometry and branch selection, five parameter ratios, exact common tolerance, and 68 small observation definitions. If a record's true allowed output interval is \(Y_{ik}(\theta)\), each candidate passes a sufficient test when \(\sup_{v\in Y_{ik}(\theta)}|v-y_{ik}|\le\delta\) for every row. A nonnegative threshold chosen from an affine fit is a conditional discrepancy parameter. It does not establish experimental uncertainty, timing or registration. Require the larger-radius contrasts to lie in two separated intervals under the same prespecified input and without re-fitting. Numerical stationarity, Q8/Q12 cross-evaluation, and exact P2 interpolation have different scopes. A finite-model equilibrium witness needs a bound on the actual equilibrium-position error and its effect on all observables. A biological statement needs the source time, reference growth, ROI, geometry, uncertainty, and dynamic or branch compatibility. [Observation contract](../../../docs/JOINT-OBSERVATION-CONTRACT.md)

Let \(I_-,I_+\) be certified response intervals for the two admitted point witnesses. If their distance \(\gamma>0\), the triangle inequality gives a worst-case absolute prediction error of at least \(\gamma/2\) for any single scalar estimate from the shared small data, conditional on this model class. This is a lower bound on the full compatible-set radius. It does not compute the complete prediction envelope or its optimal experimental design. To distinguish the pair with a measurement of the *same* \(Q\), outside already-incorporated errors, expand each interval by its additional observational and model discrepancy radius. A sufficient strict criterion is \(\eta_-+\eta_+<\gamma\). With a common additive contrast error bound it is \(2\eta<\gamma\). If two heights are measured separately with a deterministic error cap \(b\) each, then \(\eta\le2b\) from height errors alone, and \(4b<\gamma\) would suffice only with the remaining registration, time, and model uncertainties already controlled. Shared error structure can change the bound only if demonstrated. No numeric required measurement precision is justified by the current affine width or the stored-curve interpolation margins.

This search weakens broad originality claims. If a pair passes both frozen tests, label the first result by its actual scope and retain the tolerance and uncertainty margin. If either constraint test or separation fails, keep the counterexample attempt. A bounded search with no identical application found cannot establish a priority claim. A quantitatively validated all-68/no-refit epithelial pair with an attainable registered measurement precision would make the comparison sharper. The current evidence leaves that application-level contribution open.
