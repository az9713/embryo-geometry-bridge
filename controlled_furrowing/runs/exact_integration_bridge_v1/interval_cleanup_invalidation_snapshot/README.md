# Embryo Geometry Bridge

An evidence-audited study of how molecular activity, tissue mechanics and geometry relate during embryonic development, with avian observations and a separate controlled-furrowing study in Drosophila. **The full 15-step project remains incomplete.** No confirmed new concept or validated molecular-to-3D-shape prediction is claimed.

Open [the HTML dossier](docs/index.html), [science and proofs](docs/SCIENCE.html), [findings and limits](docs/FINDINGS.html), or the [Space execution dossier](../../../../OMITTED.html). This repository is local; no new GitHub Pages deployment is claimed.

.venv-scientific-replay/Scripts/python.exe -m pip install -r requirements-scientific.txt
$researchPython = Join-Path $PWD '.venv-scientific-replay/Scripts/python.exe'
