# Uniform full-B reduction: non-executable preparation specification

No actual combined result is accepted by this preparation document. A runnable
protocol will be frozen only after the coordinator supplies actual terminal
exit evidence and exact result hashes for BOTH completed producers.

Declared sources are uniform_bulk_assembly_B_safe_v2 and
uniform_surface_B_safe_v2. The surface actual terminal has been reported;
the bulk actual terminal is still required. No partial bulk packet or elapsed
time implies completion. No duplicate integration or physical solver job is
authorized here.

The final reducer must verify all144 bulk and24 surface packets, including
the seven explicitly reused completed safe-pilot records and137 fresh bulk
records. It will bind exact selectors, current source/prelaunch/domain hashes,
the common five-coordinate C, dose, geometry box, original normalized target,
611 free-coordinate maps, local domain and derivative-tail policies. It will
retain exact rational endpoint sums for611F and6676 upper-Hessian slots,
including unsorted maps, shared nodes and Hessian symmetry.

Let Hbox be those combined Hessian-discrepancy entry enclosures. Set
h_j=Σk sup|Hbox_jk|. Using the original binary preconditioner as exact rationals,
the independent conservative bound is

    b_row=max_i Σj |R_ij| h_j.

A separately declared signed Arb256 matrix product R·Hbox may also provide a
valid upper bound, with its own retained row bounds and compressed exact
endpoint output. The minimum of valid bounds is valid. It is not evidence of
a physical optimization or a lower bound. Matrix arithmetic is not an
independent reintegration of the local moments; reviewed generic engines and
the new independent prelaunch domain proofs are explicit reuse.

The original safe point u0/theta0 must be shown to belong to the common nodal
box and C. Necessary local/global safe-point interval overlaps are consistency
checks; overlap is not itself proof of uniformity or a requirement that a
uniform enclosure contain every bit of a separately rounded point enclosure.

The exact absolute-row bound, optional signed matrix bound, all611 H rows and
signedR·F endpoints will be retained even if the bound is too large to transfer
a contraction. Failure of a sufficient norm test never means no integral root.
This first version certifies only the supplied frozen physical/model family;
it does not substitute improved axis-edge packets without a separately frozen
equivalence/selection revision. No integral-root, PDE, observation-alignment,
physical-domain closure or original-five-gate completion is claimed.
